# PreuSync Web Admin Panel (v1.0.0)

El **Panel de Administración Web de PreuSync (`preusync-admin`)** es una aplicación SPA (Single Page Application) independiente, ultrarrápida y responsiva diseñada para la gestión integral de la plataforma educativa PreuSync.

## 🚀 Características Principales

1. **Editor Dinámico de Horarios Escolares**:
   - Edición interactiva de la matriz de 16 turnos por escuela y grupo.
   - Guardado atómico de turnos, duraciones y materias en tiempo real.
2. **Jerarquía Nacional (Multi-Tenancy)**:
   - Consulta y administración de Provincias, Municipios, Escuelas e Instituciones Educativas.
   - Gestión de grupos oficiales (`school_groups`).
3. **Gestión de Contenidos y Noticias**:
   - Publicación de noticias destacadas para carruseles.
   - Moderación de publicaciones de la comunidad.
4. **Gestión de Usuarios y Roles**:
   - Verificación de cuentas, consulta por username y asignación de privilegios.
5. **Centro de Moderación y Reportes**:
   - Revisión de denuncias y seguimiento de reportes de bugs.

## 🛠️ Tecnologías

- **HTML5 + ES6 Modules** (SPA sin dependencias complejas de construcción local)
- **Tailwind CSS** (Diseño moderno, fluido con soporte completo para modo claro/oscuro)
- **Lucide Icons** (Iconografía vectorial estandarizada)
- **API REST Live**: Conectado directamente a `https://preusync-api.onrender.com/api`

## 🌍 Despliegue

Puedes desplegar este panel admin en cualquier servicio de hosting estático como **Render Static Site**, **Netlify**, **Vercel** o **GitHub Pages**.
